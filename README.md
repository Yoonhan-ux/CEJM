# CEJM – BTS MCO

Application de révision de CEJM (Culture économique, juridique et managériale) pour le BTS MCO : notions, flashcards, quiz et études de cas type examen, 1re et 2e année séparées.

## Mettre en ligne avec GitHub Pages
1. Crée un dépôt sur github.com (par ex. `cejm-bts-mco`).
2. Dépose **tout le contenu** du dossier (`index.html`, `manifest.webmanifest`, dossier `icons`, `README.md`) à la racine du dépôt.
3. Va dans **Settings > Pages**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Après 1 à 2 minutes, l’app est disponible sur `https://TON-PSEUDO.github.io/cejm-bts-mco/`.

## Ajouter à l’écran d’accueil
- iPhone (Safari) : Partager > Sur l’écran d’accueil.
- Android (Chrome) : menu ⋮ > Ajouter à l’écran d’accueil.
